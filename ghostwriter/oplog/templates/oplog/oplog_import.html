CSV reference

Prepare the export

Use an export from Ghostwriter when possible; it already carries the expected header and timestamp shape.

Required headers

entry_identifier, start_date, end_date, source_ip, dest_ip, tool, user_context, command, description, output, comments, operator_name, tags

entry_identifier may be empty or unique. An optional extra_fields column accepts a JSON object keyed by extra-field internal name.

Timestamp format

Use YYYY-MM-DD HH:MM:SS for start_date and end_date, matching a Ghostwriter export.

Include a timezone offset such as +00:00. Without one, Ghostwriter uses the server timezone ({{ TIME_ZONE }}).
