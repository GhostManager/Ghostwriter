Import Requirements

Required CSV Headers

Your CSV file must have these headers:

entry_identifier, start_date, end_date, source_ip, dest_ip, tool, user_context, command, description, output, comments, operator_name, tags

The entry_identifier field may be empty or contain a unique value. If it matches an existing entry, the import updates that entry.

An optional extra_fields column may contain a JSON object keyed by extra-field internal names.

Timestamp Format

Use YYYY-MM-DD HH:MM:SS for start_date and end_date. Match the timestamp format produced by a log export.

Include a timezone offset such as +00:00. Without one, Ghostwriter uses the server timezone ({{ TIME_ZONE }}).
