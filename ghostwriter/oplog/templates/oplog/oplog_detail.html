Quick reference

Shortcuts and workflow cues for keeping the current log moving.

Live updates

Entries are kept in sync via WebSockets. The Connected / Disconnected indicator in the toolbar shows the current connection state.

Changes made by other operators appear automatically — no refresh needed.

Entry defaults

Use Entry Defaults to pre-fill Source, Destination, and User Context for entries created with Create Entry, Ctrl+N, or Cmd+N.

Defaults remain only on this page and clear when it reloads or closes. They do not overwrite existing or copied entries.

Navigation and selection

  • Click a row to open the details pane; double-click to edit it.
  • ↑↓ arrow keys move between entries once one is selected; Enter opens its edit form.
  • Ctrl+Enter or Cmd+Enter saves the edit form and closes it. Esc closes the details pane and returns the table to full width.
  • Ctrl+N or Cmd+N creates a new entry.
  • Typing @today/@date or @now/@time, followed by a space or punctuation in rich text, inserts the current date or time.

Sorting

  • The default order is start date, newest first.
  • Click a column header to sort; Shift+click additional headers to add a secondary sort.
  • Sort preferences persist. Use Reset Sort to restore the default.

Columns

Click Columns to toggle individual columns. Your preferences are saved in your browser.

Long-form fields are truncated in the table; select an entry to read its full content in the details pane.

Filtering

Use Filter Entries to search across every field, including fields hidden from the current table and terminal recording input or output.

Results update as you type. Clear the field or select to remove the filter.

Details and deep links

The details pane includes full entry content, evidence attachments, and a terminal recording player.

Use the deep link action to copy a URL that opens the log directly at an entry.
