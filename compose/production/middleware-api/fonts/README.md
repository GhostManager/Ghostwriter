# Custom fonts for PDF rendering

Place `.ttf` or `.otf` font files here so that DOCX-to-PDF conversion uses them. For example, add **Segoe UI** (and related families such as Segoe UI Semibold, Segoe UI Light) so that generated PDFs match the appearance of your Word templates.

After adding or changing font files, rebuild the middleware-api Docker image so the new fonts are included.

**Note:** Segoe UI is a Microsoft font. You are responsible for having the right to use and distribute any fonts you add here.
